# 纸上有光｜立体卡片设计展

“纸上有光”是一座只存在于浏览器里的小型卡片设计博物馆。它收录了 40 张半个手掌大小的中文设计卡片，以真实印刷比例组织成一条可以不断向下参观的电子长卷。

## 展览内容

- 5 种卡片尺寸：迷你竖卡、标准横卡、方形卡、标准竖卡、长条卡
- 10 种视觉语言：原子废土、原子朋克、日系清新、高饱和孟菲斯、瑞士国际主义、粗野主义、活版印刷、半透明亚克力、金属铭牌与超现实编辑
- 每类风格 4 张、每种尺寸 8 张，共 40 张独立构图
- 所有文案均为中文原创微文案

## 设计方式

整场展览没有使用图片、外部字体、框架或生成式图片模型。卡片中的纸张、压印、旧化、折射、金属高光、套印偏移与立体边缘，全部由 HTML 和 CSS 构成。

页面采用日系白色纸张式展馆作为中性背景，让不同风格的作品保持各自个性。鼠标经过卡片时，光影会随指针轻微移动；点击作品可进入深色聚光灯查看器，并通过按钮或方向键连续参观。

## 使用方式

直接打开 [`index.html`](./index.html) 即可离线参观，无需安装依赖或启动开发环境。

支持：

- 桌面、平板与手机响应式布局
- 鼠标 3D 倾斜与移动端轻触反馈
- 键盘方向键切换、`Esc` 关闭查看器
- 系统“减少动态效果”偏好
- 完全离线运行

## 作品边界

原子废土分区借鉴复古核能宣传、避难通知、旧纸与工业编号等公共视觉语言，不使用现成游戏角色、Logo 或受版权保护的图像素材。

---

形式不是装饰。比例、间距、层次与材料感，共同决定一张小卡片如何被记住。
